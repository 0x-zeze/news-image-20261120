## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` draws `entry.png` (1024×1024, Pillow, no network, deterministic) and writes it to `$MAKEFUN_OUTPUT_DIR` (or `/output`); if Pillow is unavailable it copies the pre-rendered `entry.png` shipped in this repository, drawn by the same program.
